MAVROS 2 facts (verified in-container): run mavros_node WITHOUT namespace (namespace 'mavros' gives /mavros/mavros/*); plugin sub-node params are NOT loaded from YAML (only plugin allow/denylist on /mavros works); /mavros/state is RELIABLE+TRANSIENT_LOCAL; flow on /mavros/optical_flow/raw/optical_flow; RANGEFINDER on /mavros/rangefinder/rangefinder; /mavros/sys_status has sensors_health; geoid install needs apt geographiclib-tools. Fake FCU test scripts /tmp/claude-0/fake_fcu.py, fake_fcu4.py (ephemeral; fake_fcu4 streams only on request, forwards a 100 Hz sensor at sysid 42, controlled via /tmp/claude-0/fcu_ctl). Env activation helper: /tmp/claude-0/rosenv.sh (micromamba binary is /tmp/claude-0/mm/micromamba). Don't pass -p no:launch_testing to pytest there.

Gotchas found: rclpy.init() context manager is not in Jazzy; colcon fails with setuptools>=80 (--editable); launch_testing plugin breaks with pytest 9; venv reached via PYTHONPATH in env.sh. In-container ROS: micromamba env at /tmp/claude-0/mm (robostack-jazzy; packages.ros.org is blocked) - ephemeral, reinstall if needed.

rclpy: one log call site cannot switch severity between calls (raises; crashed safety_supervisor once). Bench scenarios: tools/bench_test.py (starts its own safety+command nodes with a fake vehicle).

ArduCopter SITL (Phase 8, ephemeral, rebuild if gone): binary /tmp/claude-0/sitl/ardupilot/build/sitl/bin/arducopter, build venv /tmp/claude-0/sitl/venv (empy 3.3.4, dronecan, setuptools<70). Indoor params /tmp/claude-0/sitl/run/indoor.parm (SIM_GPS_DISABLE 1, GPS1_TYPE 0, FLOW_TYPE 10, SIM_FLOW_ENABLE 1, RNGFND1 analog orient 25, EK3_SRC1 POSXY 0 VELXY 5 VELZ 0 POSZ 2 YAW 1, SIM_SONAR_POS_Z -0.14). Start with (./start_sitl.sh > log 2>&1) & (nohup/setsid makes it die). SITL flow quality ~51, so sitl_drone.yaml uses flow_min_quality 40 and must mirror drone.yaml otherwise (a stale takeoff_start_timeout once faked failures). ArduCopter needs ~2.5-3 s from takeoff cmd to lift-off.

Packaging: /tmp/claude-0/package.sh N; README status: /tmp/claude-0/set_status.py.
